## About Wispers Access

Wispers Access makes it as easy as possible to share web apps with your
coworkers or friends without having to publish them to the internet.

As a host, you

1. add a sidecar process (`waserver`) to your web app
1. generate invite codes and share them with people

As a guest, you

1. install the client for your device (desktop, Android, iOS)
1. scan or copy the invite code

Done! Your web app now gets authenticated requests from your guests.

Under the hood, Wispers Access is built on [Wispers
Connect](https://connect.wispers.dev), an open-source library that connects apps
using secure and cloud-independent peer-to-peer connections. It runs at the
application level, so it will coexist nicely with your VPN.
